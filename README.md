## ✨ 核心功能特色

### 1. 📚 階梯式錦標賽完整課程 (Syllabus)
- **Level 1: 撲克數學與錦標賽基石**（底池賠率、EV 期望值、SPR、M-Ratio）。
- **Level 2: 籌碼深度與翻前範圍矩陣**（100bb+, 40bb, 20bb, 10bb 推折與防守）。
- **Level 3: 翻後 GTO 與剝削策略**（C-bet 尺度與頻率、牌面結構乾濕度、Bluff Catcher）。
- **Level 4: 錦標賽核心動力 (ICM & PKO)**（獨立籌碼模型、錢圈泡沫期大盲施壓、決賽桌階梯跳獎、獵頭賽 Bounty Factor）。
- **Level 5: 現場線下賽事實戰**（TDA 國際規則、物理 Tells 觀察、多日賽體力與飲食管理）。

### 2. 🗂️ 13x13 互動式動態起手牌範圍查看器 (Preflop Matrix Viewer)
- 視覺化 169 種起手牌組合（對子、同花、雜色）。
- 支援位置動態切換（UTG, HJ, CO, BTN, SB, BB）與不同籌碼深度（100bb / 40bb / 20bb / 12bb）。
- 支援行動分類（RFI 開池、面對 3-Bet 防守、Push/Fold 殘局極限）。

### 3. ⚡ Push / Fold 殘局 5 秒極速快打訓練器 (Drills Engine)
- 隨機生成牌桌情境（位置、有效籌碼、盲注結構）。
- 5 秒倒數倒計時決策，即時判定 +EV / -EV 並給出精確 Nash 均衡數值與連擊計分。

### 4. 🧠 翻後 GTO 決策測驗庫 (Scenario Quiz)
- 模擬翻牌、轉牌、河牌之實戰情境，即時回饋 GTO 頻率與最佳策略解析。

### 5. 🛠️ 錦標賽專業工具箱 (Pro Toolbox)
- **底池賠率 & 必要勝率計算機**：即時換算投資報酬率與跟注底線。
- **SPR 決策指針**：指引翻後 Commitment（套池）程度。
- **錦標賽資金管理 (BRM) & 參賽記帳**：本地儲存個人參賽記錄，自動統計 ROI、ITM% 與盈虧曲線。
- **錦標賽盲注計時器 (Blinds Clock)**：自訂升盲時間、Ante 結構與休息提醒。

### 6. 🧘 心理抗波與防上頭系統 (Mental Game)
- 7 種典型撲克「上頭 (Tilt)」自我檢核與重啟 SOP。
- A-Game / B-Game 狀態管理檢驗清單。

## 🛠️ 本地開發與運行 (Quick Start)

### 環境需求
- Node.js 18+ 
- npm 或 pnpm / yarn

### 安裝與啟動
```bash
# 1. 安裝依賴套件
npm install

# 2. 啟動本機開發伺服器
npm run dev

# 3. 建置生產環境版本
npm run build
```
